# Product Scope

## 产品定位

SWE Agent Harness 是一个本地优先、模型可替换、以安全工具执行和可审计修复闭环为核心的 Python Agent 运行时。

## 目标用户

- 希望理解并定制 coding agent 的开发者；
- 需要把私有工具或 MCP 接入代码修复流程的团队；
- 需要可重复评测 Agent 行为的研究与工程场景。

## MVP 完成定义

给定一个小型 Python Git 仓库和明确缺陷描述，Agent 能够：

1. 搜索并读取相关代码；
2. 形成短计划；
3. 在权限策略内编辑文件；
4. 运行指定测试；
5. 根据失败结果至少进行一次修正；
6. 输出修改摘要、测试结果和 Git diff；
7. 留下可重放的结构化轨迹。

当前实现已覆盖这条纵向闭环；下一阶段重点是用真实模型和更多缺陷任务测量可靠性，而不是继续增加未经验证的工具数量。

## MVP 非目标

- 不训练或微调基础模型；
- 不提供 IDE 插件或桌面 GUI；
- 不承诺操作系统级安全隔离；
- 不支持任意语言的完整 LSP 能力；
- 不以多 Agent 数量作为能力指标；
- 不追求无人审批地执行破坏性操作。

## 质量门槛

- 核心逻辑离线可测；
- 每个危险能力先有权限测试再开放；
- 所有公开能力有明确失败语义；
- README 不写未测量的成功率或性能数字；
- 每个里程碑同时更新架构决策和限制说明。
