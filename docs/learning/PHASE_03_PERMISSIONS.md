# Milestone 3：权限与命令执行

## 三态权限

- `allow`：只读观察，或 auto-edit 模式下的精确文件编辑；
- `deny`：只读模式下的写入/执行，以及所有 destructive 工具；
- `ask`：需要当前用户明确批准一次。

工具是否注册与本次调用是否授权是两件事。注册表描述“系统有什么能力”，权限策略判断“此时能不能用”。

## 为什么命令参数使用数组

`["python", "-m", "unittest"]` 直接传给进程 API，且 `shell=False`。这样 `;`、`&&`、重定向等字符不会自动获得 Shell 语义，降低命令拼接注入风险。

但这不是沙箱：用户批准的 Python 程序仍可能访问工作区外资源，因此命令始终需要审批。

## 三种模式

- `read-only`：只允许观察；
- `ask`：写入和命令逐次询问；
- `auto-edit`：自动允许 `edit_file`，命令仍逐次询问。
