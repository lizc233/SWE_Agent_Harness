## 消息顺序练习

请写出“用户要求读取 `buggy_math.py`，模型调用 `read_file`，然后给出回答”时的五条消息角色顺序。

状态：2026-11-12 已通过。标准角色顺序为：

```text
system
user
assistant（携带 tool_calls）
tool（携带对应的 tool_call_id）
assistant（最终文本，不再调用工具）
```

学习者最初使用七个运行步骤描述了同一过程：调用模型、追加消息、执行工具、返回结果、再次调用模型、追加消息、无工具调用时返回。该描述在运行时层面正确。
